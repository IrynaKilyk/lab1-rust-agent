## 04.10.2026 — Manifest агента build-engineer

**Запит 1 до Copilot (режим Agent):**
Створити `.github/agents/build-engineer.agent.md`: роль, область відповідальності, skills, правила роботи з файлами, заборонені дії, порядок роботи, критерії завершення. Українською мовою.

**Відповідь Copilot:**
Створив файл із YAML frontmatter (name, description, tools) і розділами 1-7.

**Підтвердження:**
Copilot запитав дозвіл на редагування чутливої папки `.github`. Дозволено, бо це цільовий файл агента.

**Перевірка та виявлена проблема:**
Перевірочний PowerShell-скрипт показав, що в manifest бракує: переліку commands, правила зупинки при першій помилці, `build/hello.exe` для Windows, заборони на секрети у workflow та `rm -rf`. Скрипт завершився з exit code 1.

**Запит 2 (виправлення):**
Надіслала Copilot перелік нестач. Він додав розділ «Доступні commands», правило зупинки при першій помилці, `build/hello.exe` для Windows і додаткові заборони. Повторна перевірка пройшла успішно.

**Запит 3 (додаткове виправлення):**
Під час перегляду manifest помітила дві невідповідності методичці: розділ «Доступні commands» був без номера, а опис `git-init` не згадував створення `.gitignore`. Третім запитом Copilot перейменував розділ на «3a. Доступні commands» і доповнив опис `git-init` (створення або оновлення `.gitignore` з `target/` і `build/`, без дублювання рядків).

**Рішення:**
Зміни переглянула в Source Control і прийняла (Keep).

**Висновок:**
Перша версія manifest була неповною. Автоматична перевірка допомогла знайти пропуски, які виправлені через AI, а не вручну.
